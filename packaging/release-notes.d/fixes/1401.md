- Importing mail that is already there no longer duplicates it ([#1401](https://github.com/UCS-Care-Group/mailcraft/issues/1401)): Import and Import a Folder of Mailboxes leave out a message the mailbox already holds anywhere (same Message-ID, date, sender, subject and recipients) and say how many were already there. An .mbox or .eml file dropped on the window, or opened from the file manager, now asks first how many messages it would import and where. Mail imported into a folder of an IMAP, JMAP or Exchange server account goes to the local folder Imported, as it already did for a Microsoft account, so it is never mistaken for the server's mail. Export Folder and Save Message As say what they saved. Folder › Remove Imported Duplicates removes the copies earlier imports left beside the server's mail: it asks first with the count, never touches the server's copy, sends nothing to the server, and can be undone.
