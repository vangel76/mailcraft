- Importing mail that is already there no longer duplicates it ([#1401](https://github.com/UCS-Care-Group/mailcraft/issues/1401)): Import and Import a Folder of Mailboxes leave out a message the folder already holds whole (same Message-ID, date, sender, subject and recipients) and say how many were already there. Mail imported into another folder, such as an archive on this computer, still comes in whole. An .mbox or .eml file dropped on the window, or opened from the file manager, now asks first how many messages it would import and where. Mail imported into a folder of an IMAP, JMAP or Exchange server account goes to the local folder Imported, as it already did for a Microsoft account, so it is never mistaken for the server's mail. Export Folder and Save Message As say what they saved. Folder › Remove Imported Duplicates removes the copies earlier imports left beside the server's mail: it asks first with the count, keeps any copy you flagged, categorised, read or made a to-do from, never touches the server's copy, sends nothing to the server, and can be undone until the next Send/Receive.
